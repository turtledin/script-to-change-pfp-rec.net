# Utilizing rec.net API to change your profile picture

## How to Use
To use you will need to be logged in to rec.net and have the browser console open.

Next just paste the code from either of the JavaScript files listed below (depending on what you want to change) into the console, and you will be prompted with a text field which requires you to enter the image ID.

```javascript
settingBanner.js

settingPFP.js
```
To get the image ID, simply find the image you want to use on rec.net, then select the file name (the string of characters after the last "/" in the URL) and copy it.

example:
![example image](https://github.com/turtledin/script-to-change-pfp-rec.net/blob/tree/main/images/exampleScreenshot.jpg?raw=true)

Paste that string into the prompt and hit enter. If successful, you should see your profile picture/banner change.
